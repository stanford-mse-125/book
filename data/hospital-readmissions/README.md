# CMS Hospital Readmissions Reduction Program (HRRP) Dataset

## Data Source

- **Primary dataset**: CMS Hospital Readmissions Reduction Program
  - URL: https://data.cms.gov/provider-data/dataset/9n3s-kdb3
  - API: `https://data.cms.gov/provider-data/api/1/datastore/query/9n3s-kdb3/0?offset={OFFSET}&count=true&results=true&schema=true&keys=true&format=csv&rowIds=false`
  - File: `hrrp_full.csv`
  - Downloaded: 2026-03-11
  - Must paginate in batches of 1500 rows (API limit)

- **Supplementary dataset**: CMS Hospital General Information
  - URL: https://data.cms.gov/provider-data/dataset/xubh-q36u
  - API: same pattern with dataset ID `xubh-q36u`
  - File: `hospital_info.csv`

### Download Instructions

```python
import urllib.request, csv, io

base = 'https://data.cms.gov/provider-data/api/1/datastore/query/9n3s-kdb3/0?offset={}&count=true&results=true&schema=true&keys=true&format=csv&rowIds=false'
all_rows, header, offset = [], None, 0
while True:
    resp = urllib.request.urlopen(base.format(offset))
    text = resp.read().decode('utf-8')
    rows = list(csv.reader(io.StringIO(text)))
    if header is None: header = rows[0]
    data = rows[1:]
    all_rows.extend(data)
    if len(data) < 1500: break
    offset += 1500
# Write to CSV...
```

## Schema

| Column | Type | Description |
|--------|------|-------------|

| `Expected Readmission Rate` | float | National average rate adjusted for this hospital's patient mix |
| `Number of Readmissions` | string | Actual readmission count (or "Too Few to Report") |
| `Start Date` | string | Performance period start (07/01/2021) |
| `End Date` | string | Performance period end (06/30/2024) |

**Six conditions tracked:**
- `READM-30-AMI-HRRP` — Acute Myocardial Infarction (heart attack)
- `READM-30-CABG-HRRP` — Coronary Artery Bypass Graft (heart surgery)
- `READM-30-COPD-HRRP` — Chronic Obstructive Pulmonary Disease
- `READM-30-HF-HRRP` — Heart Failure
- `READM-30-HIP-KNEE-HRRP` — Hip/Knee Replacement
- `READM-30-PN-HRRP` — Pneumonia

### Missing Data (critical for teaching)

| Column | % Missing | Pattern |
|--------|-----------|---------|
| Number of Discharges | ~15% | MNAR: "Too Few to Report" — disproportionately small/rural hospitals |
| Footnote | ~85% | Only present when there's a data quality issue |
| Excess Readmission Ratio | ~15% | Same hospitals as missing discharges |

**Missingness varies by condition**: CABG (heart surgery) has ~50% missing because fewer hospitals perform this procedure. HF and COPD have ~5-10% missing.

### Excess Readmission Ratio

- Mean: ~1.00 (centered by construction)
- Std: ~0.07
- Range: roughly 0.7 to 1.5
- About 45-50% of hospital-condition pairs have ratio > 1.0

## Naive Analysis Traps and Pedagogical Hooks

### 1. Simpson's Paradox (Confounding)

**The core trap**: Hospitals treating sicker patients (higher Expected Readmission Rate) naturally have higher raw readmission counts. A naive analyst ranking hospitals by raw readmission rate would penalize academic medical centers and safety-net hospitals.

CMS addresses this with the **Excess Readmission Ratio** = Predicted / Expected. But:
- The adjustment may be incomplete (residual confounding from unmeasured SES factors)
- Research shows HRRP disproportionately penalizes safety-net hospitals serving low-income populations

**Teaching moment**: Have students compare naive rankings (by predicted rate) vs adjusted rankings (by excess ratio). Which hospitals move most? Why?

### 2. Data Leakage

A naive analyst asked to "predict readmission performance" would likely include `Expected Readmission Rate` as a feature — but this is mathematically part of the target variable (`Excess Readmission Ratio = Predicted / Expected`). This is textbook data leakage.

### 3. Missing Not At Random (MNAR)

The "Too Few to Report" entries are not randomly missing. They are systematically small/rural hospitals with low case volumes. Dropping them (which a naive analysis would do) biases the analysis toward large urban hospitals.

### 4. Unit of Analysis Confusion

The data is at the hospital-condition level (long format). Naively averaging across conditions (AMI rate ~15%, HIP-KNEE rate ~4%) produces meaningless hospital-level scores. Proper analysis requires condition-specific models or discharge-weighted averages.

### 5. Ecological Fallacy

Hospital-level readmission rates cannot be used to make claims about individual patient outcomes. A 15% hospital readmission rate does not mean each patient has a 15% chance of readmission.

### 6. Label Encoding of Categoricals

Hospital ownership and type are nominal (unordered) categories. Label encoding them as integers (which scikit-learn's default pipelines do) implies a false ordering.

### 7. Ignoring the Policy Mechanism

The HRRP financially penalizes hospitals with excess readmissions (up to 3% Medicare payment reduction). This creates:
- **Incentive effects**: hospitals may game metrics (observation stays, patient selection)
- **Feedback loops**: penalized hospitals lose revenue, potentially reducing care quality
- **Causal complexity**: the "treatment" (penalty) affects the "outcome" (readmissions) through behavioral channels, not just care quality

## Suggested Uses by Lecture

### EDA (Weeks 1-3)
- Explore distributions, identify outliers, characterize missing data
- Practice: histograms, boxplots, scatter plots, correlation matrices
- Discuss why the data looks the way it does (structural zeros, truncation, etc.)

### Regression (Weeks 4-6)
- Predict Excess Readmission Ratio from hospital characteristics
- Demonstrate data leakage by including Expected Rate as a feature
- Compare naive OLS vs condition-specific models
- Discuss R-squared interpretation and residual analysis

### Classification (Weeks 7-9)
- Binary: will hospital be penalized? (Excess Ratio > 1.0)
- Multi-class: CMS star ratings (1-5) from hospital characteristics
- Demonstrate class imbalance, threshold selection, and precision-recall tradeoffs

### Causal Inference (Weeks 10-12)
- Does the HRRP penalty actually reduce readmissions? (pre/post comparison across years)
- Confounding: do safety-net hospitals get unfairly penalized? (need to control for patient SES)
- Simpson's paradox as a motivating example for DAGs and adjustment
- Natural experiment: some conditions were added to HRRP at different times (staggered treatment)

### Capstone / Final Project
- Combine all techniques: EDA -> regression -> classification -> causal analysis
- Students can pick a specific condition, state, or hospital type to focus on
- Compare their conclusions with/without proper statistical adjustments
